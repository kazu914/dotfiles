# Herdr セッションダッシュボード

Claude Code、Codex、OpenCode の稼働ペインを「応答待ち → 待機中 → 作業中」の順に確認するローカルダッシュボードです。会話履歴は別の「セッション履歴」から閲覧できます。Herdr が利用できない場合でも、各ツールが保存した履歴を閲覧できます。

## 必要なもの

- Python 3（Python 標準ライブラリのみを使用します）
- Herdr 0.7.4 以降（Herdr セッションとの自動紐付けを利用する場合）

## 起動

リポジトリのルートで次を実行します。

```sh
make herdr-dashboard
```

ブラウザーで <http://127.0.0.1:8765> を開いてください。サーバーはローカル閲覧用です。

## テスト

```sh
python3 -m unittest discover -s herdr/session-dashboard/tests
```

## Herdr セッションとの任意の紐付け

Herdr 0.7.4 以降をインストール済みの場合は、利用するエージェントのインテグレーションを設定できます。

```sh
herdr integration install claude
herdr integration install codex
herdr integration install opencode
herdr integration status
```

Herdr 本体とは別に、各エージェントのインテグレーションを導入する必要があります。未導入でも Herdr のペイン状態とローカルの会話履歴は閲覧できますが、両者を確実に紐付けられない場合があります。導入後は、新たに報告されたセッションから対応付けられます。

`herdr integration status` の `current` は連携ファイルが配置されていることを示し、すでに起動中のエージェントへの反映やセッション ID の報告を保証しません。Claude Code と Codex はセッション開始時の hook で ID を報告するため、連携導入前から動くセッションには参照がない場合があります。OpenCode は連携を読み込むため TUI の再起動が必要です。参照がまだないペインでは会話履歴の代わりに、Herdr が保持する端末の最近の表示を出します。両者は画面上で区別します。

セッション ID が報告済みでも、対応する会話ファイルが未作成、索引の対象外、または読み取り不能の場合は端末表示に切り替わります。会話と端末表示は同一視せず、ファイルが見つからないことだけで連携の失敗とは判断しません。

Herdr 上に対応するペインがない履歴は「非稼働」と表示します。別の端末で稼働している可能性もあるため、「終了」とは断定しません。

## プライバシーと表示設定

このダッシュボードは `127.0.0.1` にのみ公開します。会話は閲覧のみですが、ボタンから Herdr のペインに移動できます。会話ログには機密情報が含まれる可能性があります。認証機能はなく、同じ Mac の別ユーザーからもループバック経由で閲覧できるため、共有端末では起動しないでください。画面共有にも注意してください。

ペインへ移動するときに前面化する Mac アプリは既定で `Ghostty` です。変更する場合は `HERDR_DASHBOARD_TERMINAL_APP` 環境変数にアプリ名を設定してください。複数のターミナルウインドウを使う場合、アプリの前面化だけでは対象ウインドウの表示まで保証されません。
